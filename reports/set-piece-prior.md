# The set-piece prior, measured

Generated by `pnpm report:setpiece`. Season-level join of `players_raw.csv` (`penalties_order`, `direct_freekicks_order`, `corners_and_indirect_freekicks_order`) onto the per-gameweek archive, by `code`.

**Read the caveat before the numbers.** The order is a season-END value. A player who took the job in January reads as the taker for the whole season, including the four months he was not — and the job tends to go to whoever is already scoring. That biases every effect below **upward**. This is a measurement, not a model feature, and the gap between those two is exactly this paragraph.

---

**What this does NOT establish.** That the lift is causal, or that it survives the season-end bias described at the top, or that it adds anything the model does not already get from a player’s own lagged xG — which for a penalty taker already includes his penalties. That last one is the important one: the model reads xG per 90, and a penalty is about 0.76 xG. Adding a set-piece term on top would double-count unless it is fitted against the residual, and no such fit is done here.
