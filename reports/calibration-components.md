# Per-component calibration — fitted

Generated by `pnpm calibrate:components`. Held-out season **2025-26**, 29,482 scored player-rounds. Parameters fitted on 2023-24 + 2024-25.

Every table carries `n` and the base rate. A Brier score alone is a trap for a rare event: predicting "never" for a 2% event scores 0.0196 and knows nothing. `reliability` is the calibration error (0 is perfect), `resolution` is how far the model moves off the base rate when it is right, and `skill` is `1 − BS/uncertainty` — positive means better than always predicting the base rate.

## Verdict

No single term dominates. Worst is P(60+ minutes) at reliability 0.0015 against a mean of 0.0007 for the rest (2.2×) — the miscalibration is spread across components, which is a different and equally publishable answer.
